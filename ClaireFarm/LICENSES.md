# Claire's Farm: asset sources and licences

Every file that ships in this folder is listed here with where it came from. Nothing is a placeholder primitive
standing in for art; anything drawn in code (trees, crops, fences, grass, sky, water) is generated by the game's own
JavaScript. No Meshy calls were made for this edition: the Meshy models were generated earlier, on the owner's Meshy
account, for the Godot edition of the game (`claires-big-life-adventure`), and are reused here after decimation.

## Audio (`audio/`)

All sound was made for this game with ElevenLabs on the owner's Creator plan (commercial licence). No third-party
recordings are used. The arcade's shared sound kit (`assets/sfx/`, also ElevenLabs) covers taps, coins and jingles.

| Files | What |
| ----- | ---- |
| `voice/claire_01..15.mp3` | Claire's spoken lines (short, friendly, appropriate for children). |
| `music/claire_theme.mp3` | The title theme, reused from the Godot edition. |
| `music/golden_hour.mp3`, `music/lantern_night.mp3` | Day and night music beds, generated for this edition. |
| `sfx/*.mp3` | Cow, chicken, pig, sheep, dog, planting, harvest, bell, ding, horn, lantern, fireworks, day and night ambience, rain. Each has a `.json` sidecar with its prompt and creation date. |
